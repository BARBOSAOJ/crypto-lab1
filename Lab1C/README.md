# Lab 1C - Many Time Pad

13 ciphertexts encrypted with the same stream cipher key. Step 1 guesses the key using
spaces (space XOR letter = letter), step 2 uses message 11 as a crib to get the full key.

Run: `python3 lab1c.py`
